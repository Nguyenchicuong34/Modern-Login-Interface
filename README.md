###  Overview
This project is a concept for a modern, aesthetically pleasing authentication interface. It mimics the style of premium learning platforms (inspired by Skillshare) but enhanced with **Glassmorphism** design trends.

The goal was to create a fully responsive layout that looks great on both Desktop and Mobile devices without using any CSS framework (Pure CSS).

###  Key Features
* ** Glassmorphism Effect:** Using `backdrop-filter: blur()` and semi-transparent backgrounds to create a depth effect.
* ** Fully Responsive:** Adaptive layout using Flexbox (switches from Row to Column on mobile).
* ** Interactive UI:** Password visibility toggle (Show/Hide) feature implemented with Vanilla JS.
* ** Animations:** Smooth entry animations (`fadeIn`) and button hover effects.
* ** Social Login Layout:** Structured layout for third-party authentication (Google, Facebook, GitHub, etc.).

###  Tech Stack
* **Structure:** Semantic HTML5.
* **Styling:** CSS3 (Variables `:root`, Flexbox, CSS Gradients).
* **Logic:** Vanilla JavaScript (DOM Manipulation).
* **Icons:** FontAwesome CDN.
